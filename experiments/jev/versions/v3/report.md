# Jev v3 결과: 명시 충돌 독립 검사

같은 120개 회귀 평가에서 **v2 102/120 → v3 110/120(91.67%)**로 개선됐다. 필수 질문은 46/59 → 54/59(91.53%), 과잉 질문은 0/61 유지. 충돌 유형은 11/20 → 19/20이며 정답이던 사례의 퇴행은 없었다. 별도 독립 평가와 제품 도입은 아직 하지 않았다.

## 변경과 고정 조건

v2 영어 4분류 질문은 그대로 두고 같은 요청에 noul 명시 충돌 질문을 추가했다. 같은 대상·조건에서 두 명시 요구가 양립 가능한지 검사하며, 명시된 예외는 충돌로 보지 않도록 했다. 충돌 확률 >= 0.5이면 ask_user로, 아니면 4분류 결과대로 진행한다. 임계값은 실행 전에 고정했고 결과를 보고 바꾸지 않았다.

- 같은 원문 120개, 사전 수정 정답, jev-1.13.0, 각 1회. 사용자 발화는 한국어 유지.
- HTTP 120회, 요청당 질문 2개. Sonnet·fallback·재시도 없음. 전부 정상 응답.
- 원래 4분류 결과·확률·confidence와 충돌 확률을 따로 저장했다. 충돌 분기 적용 시 최종 4분류 confidence/확률은 null이다. 서로 다른 판단을 합쳐 보정된 확률인 것처럼 만들지 않는다.
- 이미 v2 test 오류를 보고 만든 개선안이므로 이번 test 점수도 회귀 평가다.

## 결과

| 지표 | v2 120개 | v3 120개 |
| --- | --- | --- |
| 정답 일치 | 102/120 · 85% | 110/120 · 91.67% |
| dev / test | 51/60 · 51/60 | 55/60 · 55/60 |
| 필수 질문 회수 | 46/59 · 77.97% | 54/59 · 91.53% |
| 과잉 질문 | 0/61 | 0/61 |
| 충돌 유형 정답 | 11/20 | 19/20 |
| 지연 중앙값 | 206ms | 193ms |
| 입력 / 출력 토큰 | 100,754 / 6,213 | 124,754 / 8,374 |
| 계산 비용 USD | 0.004231668 | 0.005239668 |

비용은 약 23.8% 증가했다. 관측 지연은 줄었지만 한 번씩 실행한 결과라 구조 변경이 속도를 개선했다고 단정하지 않는다. 사전 비용 예상 USD 0.006–0.015, 보수적 요청 허용량 합계 USD 0.039938808, 실행 예산 USD 0.05였고 실제 계산 비용은 예상보다 낮았다. 전체 기록상 누적 계산 비용은 USD 0.146618414다. 청구서 확인 금액은 아니다.

## 어떤 사례가 개선됐는가

v2의 오답 CONFLICT-05·06·07·10·15·18·19·20 총 8개가 ask_user로 개선됐다. 기존 정답의 최종 퇴행은 0개다. 명시 예외 CONFLICT-16은 ready를 유지했다.

기본 4분류만 보면 103/120이었다. 저장된 v2와 기본 분류가 달라진 항목은 CONFLICT-03(ask_user→ready), CONFLICT-05·15(ready→ask_user)다. 따라서 8개 개선을 전부 독립 충돌 질문만의 효과라고 주장하지 않는다. 이번 실행 내부에서 충돌 분기가 기본 ready 7개를 ask_user로 보완해 103/120 → 110/120을 만들었다. 충돌 확률이 0.5 이상인 것은 17개였고 그중 10개는 기본 분류도 이미 ask_user였다.

## 남은 오류 10개

- CORE-05·07·11: 핵심 의도 누락을 ai_refine으로 처리.
- DEFAULT-02·04·10·16·20: Spec 이관 대상을 ai_refine으로 처리.
- CONFLICT-14: 명시 충돌을 ready로 처리. 독립 충돌 확률도 0.22로 낮았다.
- SCOPE-12: 지원 기술 스택 충돌을 ready로 처리. 이번 독립 검사는 사용자 명시사항끼리의 충돌을 대상으로 하므로 지원 정책과의 충돌은 기본 분류가 담당한다.

필수 질문 누락은 13개에서 5개로 줄었지만 해결되지는 않았다. Spec 경계 오류 5개도 그대로다. 다음 변경은 별도 버전으로 남기고 신규 독립 사례 및 반복 검증 전까지 일반화·Sonnet 대비 우월성·실제 UX 향상을 주장하지 않는다. 이번 사전 개선 기준(전체 정답·필수 질문 회수 증가, 과잉 질문 0 유지)은 충족했다.

## 실행과 버전 분리

사용자의 v2 커밋 요청이 도착했을 때 v3 120회는 이미 완료돼 있었다. v3 변경을 임시 보관하고 당시 v2 실행 코드 해시 일치와 테스트 34개를 확인한 뒤 **51cd115 feat:exp_v2**로 v2만 커밋했다. 이후 v3를 복원해 실제 실행 로그의 코드·프롬프트 해시 일치를 확인했다. 중복 과금을 피하려고 같은 실험을 재호출하지 않았다.
