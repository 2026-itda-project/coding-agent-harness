# v3: 명시 충돌 독립 검사

v2 영어 4분류 질문은 그대로 두고, 같은 요청에 noul 충돌 질문 하나를 추가한다. 충돌 확률 >= 0.5면 ask_user, 아니면 기존 4분류 결과를 유지한다. 임계값은 실행 전에 고정하며 이번 결과로 조정하지 않는다. 최종 경로를 합성한 confidence/확률 분포는 만들지 않는다. 각 판단 원본을 따로 보존한다.

- 범위: 지연·비용을 포함한 Jev 순수 판정 실험. 제품 연결 및 Sonnet 재검토는 후속 범위다.
- 같은 원문 120개와 사전 수정 정답, jev-1.13.0, 1회. 기존 결과를 본 회귀 평가이며 독립 검증이 아니다.
- 비교: v2 102/120, 필수 질문 46/59, 과잉 질문 0/61. 명시 충돌 9개 누락과 예외 CONFLICT-16의 퇴행 여부를 확인한다.
- 잠정 성공 기준: 전체 정답 및 필수 질문 회수가 v2보다 증가하고 과잉 질문은 0 유지. 충족해도 제품 도입은 별도 판단이다.
- 비용 예상: Jev 120 HTTP 요청(각 2개 질문), USD 0.006–0.015. 실행 예산 USD 0.05, Sonnet 0회. usage 기준 실비와 지연을 기록한다.
- 추가 질문이 기본 분류 출력에 미치는 영향도 관찰한다. 저장된 v2와의 비교에 실행 변동이 포함됨을 명시한다.
- 원본 API 로그는 results에 보존하고 정제 결과만 버전 폴더에 저장한다. v0/v1/v2 결과는 수정하지 않는다.
