# Sonnet 단독 120개 비교 계획

v4는 진행하지 않는다. Jev v3 커밋 0345339의 저장된 120개 결과와 Sonnet 5.5 신규 실행을 비교한다.

- 같은 한국어 원문·판단 대상·사전 정답·순서, 1회 실행. 기존 v2 영어 4분류 instructions/criteria를 Sonnet에 전달한다.
- Sonnet은 4분류 단독, Jev v3는 4분류+독립 충돌 검사다. 구성 비교이며 구조를 통제한 모델 단독 우열 실험은 아니다. 같은 영어 4분류의 저장된 Jev v2 성적도 참고한다.
- 모델 claude-sonnet-5-5, 출력 상한 1024, thinking API 기본값, Structured Output. 추출·생성·fallback·자동 재시도 없음.
- 예상 USD 0.6–1.2, 실행기 예산 검사 USD 1.20. 호출 전 누적 비용+보수적 다음 요청 예산을 검사한다. 공급자의 청구 상한은 아니다.
- Jev 추가 호출 없이 Sonnet 120회만 실행한다. 오류 시 중단하고 호출 로그부터 확인한다.
- 전체 정답, 필수 질문 회수, 과잉 질문, 유형별 오류, 지연, 사용량·비용을 비교한다. 모델에 정답·사례 유형·이유를 보내지 않는다.
- 이 120개는 이미 튜닝에 활용한 합성 평가셋이다. 신규 독립 검증·실제 사용자 경험·E2E 생성 성공률을 의미하지 않는다.
