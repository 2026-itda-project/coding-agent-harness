## 브라우저 테스트 실행

먼저 `frontend`에서 `npm run build`를 실행한다. Python Playwright와 Chromium이 설치된 별도 테스트 환경에서 다음을 실행한다. 프로젝트 런타임 의존성이나 lockfile에 브라우저 패키지를 추가하지 않는다.

```bash
python frontend/tests/user_flow_smoke.py
```

기존 Chromium을 쓰면 `PLAYWRIGHT_CHROMIUM_EXECUTABLE`로 경로를 지정한다. Linux 공유 라이브러리를 사용자 캐시에 설치했다면 테스트 프로세스의 `LD_LIBRARY_PATH`로 해당 라이브러리 디렉터리를 지정한다. 설치 경로와 패키지는 저장소 밖에 둔다.
