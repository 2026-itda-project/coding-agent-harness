## 수정과 무료 재검증

회귀 테스트는 수정 전 `maxItems`가 포함되어 실패하는 것을 확인했고, 수정 후 API 스키마에서 해당 키가 빠지면서 내부 모델은 5개를 허용하고 6개를 거부하는 것을 확인했다. 전체 백엔드 오프라인 테스트 159개가 통과했다.

## 질문부터 재개와 검토 검증 보완

검토 모델은 역할 선택 결정(`REQ-010`, scope)과 기존 이용자 역할(`REQ-002`, role)을 구분했다. 기존 검사기는 선택 역할 ID가 역할 결정 요구사항 ID와 동일해야 한다고 가정해 이 결과를 거부했다. 질문에서 참조한 기존 역할 또는 그 질문의 결정 항목을 선택할 수 있도록 수정했다. 선택한 항목의 role 유형, 단일 역할, 제외 범위, 기존 결정·출처, 수락/직접 답변/미수락 기본값 검사는 유지한다. 질문과 무관한 역할 선택은 계속 거부한다.

회귀 테스트는 수정 전 실패와 수정 후 통과를 확인했다. 전체 백엔드 160개 테스트가 통과했다. 저장된 실제 모델 응답을 수정하지 않고 무료로 재검증해 Review 상태가 통과하는 것을 확인했다. 검토 모델을 다시 호출하지 않았다.

## PRD 재개

첫 PRD는 `OUT-002: active requirement excluded without review`로 거부됐다. 사용자 입력의 '결제·메일·로그인 제외' 제약(`REQ-014`)을 Review의 `out_of_scope_ids`에 없는데도 PRD `out_of_scope`에 배치했기 때문이다. 범위 보호 검증은 완화하지 않고, 제외 목록에 없는 금지 요구사항은 `nfrs` 또는 `business_rules`의 유효한 제약으로 보존하도록 단일 역할 지침을 보완했다. 제약으로 보존하면 통과하고 임의 제외로 옮기면 거부하는 회귀 검증을 추가했다. 전체 백엔드 161개 테스트가 통과했다.

첫 PRD 계산 비용은 USD 0.077672이며 이 시점 누적은 USD 0.222082다. 추가 승인 후 같은 Run의 재시도 버튼으로 PRD부터 재개했다. 분석·질문·검토는 재호출하지 않았다.

두 번째 PRD는 선택한 역할의 설명 뒤에 행동·범위 설명을 덧붙여 `PRD must preserve the selected role`로 거부됐다. 상태·출처뿐 아니라 설명도 원문 그대로 복사해야 한다는 지침을 명확히 했다. 검사기는 완화하지 않았다. 두 번째 PRD 비용은 USD 0.087966이다.

세 번째 PRD는 계약을 통과했다. `policy=single_round_v1`, 역할 1개, `open_issues=[]`이며 선택한 역할의 설명·출처, 운영자 역할과 기능의 제외, 답변과 AI 기본값의 상태·출처를 보존했다. 비용은 USD 0.094310, 이 시점 누적은 USD 0.404358이다.

세 번째 PRD 요청 전 실험 프로세스의 PRD 하위 예산을 USD 0.5에서 1로 조정했다. 전체 요구사항·PRD·코딩을 합한 USD 5 호출 전 검사는 유지했고, 저장소의 제품 기본 예산은 바꾸지 않았다.
