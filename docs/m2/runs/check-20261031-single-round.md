# 1라운드 질문·단일 역할 정책 검증 — 2026-10-31

대상은 `feat/m2-clarification-single-role`의 `5826edb` 구현이다. 새 웹 입력의 `single_round_v1` 정책과 기존 JSON/API의 `legacy` 호환을 확인한다. 다른 PR의 후속 변경은 병합하지 않았다.

## 구현 범위

- 핵심 질문은 최대 1라운드·5개이며 질문이 없으면 바로 검토한다.
- 질문마다 AI 추천을 제공하고 개별·일괄 수락 및 거절을 지원한다. 거절하면 같은 화면에서 대안을 입력한다.
- 미질문·미응답 및 요구사항에 연결되지 않은 Gap도 검토 전에 LLM이 보완한다. 중요한 AI 결정은 별도로 확인·수정할 수 있다.
- 직접 답변, 추천 수락, 미수락 AI 기본값, Review 수정의 상태와 출처를 구분한다. 생성 버튼은 AI 제안의 일괄 수락이 아니다.
- 주 역할 하나를 선택하고 다른 역할과 전용 기능은 원문을 삭제하지 않고 제외 범위로 전달한다. 역할 수정 시 LLM이 범위를 재정리한다.
- 정책과 역할·제외 범위는 PRD, Spec, Plan, Task Context까지 전달한다. 새 정책 PRD의 Open Issue와 역할 전환은 거부한다.
- 정책이 없는 기존 JSON은 legacy로 읽고 기존 PRD 식별자와 실행 재개 계약을 보존한다.

## 무료 검증

- 백엔드 `uv run python -m unittest discover -s tests`: 최초 158개, 실제 실행에서 발견한 스키마 호환·역할 참조·제약 배치 검증 보완 후 161개 통과. Mock, 임시 Git, 로컬 HTTP를 사용하며 실제 모델과 Docker를 호출하지 않는다.
- 프론트 `npm run build`: TypeScript 검사와 Vite 빌드 통과.
- Chromium `frontend/tests/user_flow_smoke.py`: 기존 검토·생성 요청·새로고침 복구·완료·비용 차단·재시도·Open Issue·홈 복귀 통과.
- Chromium `frontend/tests/single_round_smoke.py`: 추천 일괄 수락·거절, 대안 없는 거절 차단, 질문·답변 제출, 중요한 AI 결정 수정, 역할 수정, 미수락 제안을 확정하지 않는 생성 요청 통과.

브라우저 테스트는 모든 HTTP 응답을 Mock으로 처리한다. 백엔드와 브라우저의 개별 검증을 실제 모델 E2E 성공으로 간주하지 않는다.

여러 역할을 명시한 소규모 예약 서비스 한 건으로 질문·추천·주 역할 선택부터 PRD, Spec, Plan, 코딩, Docker 점검, 생성 앱 미리보기까지 확인한다. 비용 승인 전에는 실행하지 않는다. 실패 시 기록을 보존하고 추가 유료 재호출은 별도로 승인받는다.
